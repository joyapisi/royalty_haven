# Royalty Haven Accommodations

A responsive two-page React + Vite website inspired by the supplied mobile references.

## Pages
- Landing page with Royalty Haven welcome message and a Start Exploring action.
- House Guidelines page with all seven policy sections, check-in form notice, and the **📍 OUR LOCATION** link.

## Run locally
1. Install Node.js (18 or newer).
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` to create a production build in `dist/`.

## Before publishing
Open `src/main.jsx` and replace `WHATSAPP_NUMBER` with the accommodation's WhatsApp number in international format, digits only (for Kenya, begin with `254`). The location link is already configured.
